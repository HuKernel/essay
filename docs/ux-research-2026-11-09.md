# 随记 UX 优化调研报告（2026-11-09）

> 调研范围：交互体验便捷性、布局微调、功能深化。基于代码事实（引用 文件:行号），由两个只读探查代理并行盘点 + 人工综合。
> **硬约束（用户要求）：现有布局骨架不变，只允许小幅微调，不接受位置大改。**所有布局类建议均遵循此约束。

## 现状小结

随记已具备相当完整的能力面：全局热键呼出、富文本编辑（表格/公式/Mermaid/Callout/涂鸦/块组合/折叠大纲）、多标签、命令面板、模板、双链与反链、子页面、任务提醒、FTS5 搜索、加密备份、5 主题 × 明暗。本次调研发现的优化空间主要集中在**交互效率（快捷键一致性、命令面板、批量操作）**、**反馈可靠性（保存失败、焦点管理）**和**规模化（大量笔记时的列表性能）**，而非缺大功能。

---

## A. 交互便捷性

### A1. 快捷键声明与实现不一致（快赢）
- 现状：ShortcutsModal 声称 `Ctrl+P` 是命令面板别名（ShortcutsModal.tsx:15）、`Ctrl+,` 打开设置（:17），但渲染层 keydown 均无注册（App.tsx:942-990 无对应分支；设置菜单项也无 accelerator，app-shell.ts:67-69）。
- 建议：补注册这两条；进一步把「快捷键清单」做成单一数据源常量，同时驱动 ShortcutsModal 展示与实际注册，杜绝两头漂移。

### A2. 命令面板匹配与覆盖升级
- 现状：仅子串匹配（CommandPalette.tsx:31），无拼音/首字母/模糊；结果截断 50 条；命令仅 8 条命令 + 6 条视图切换 + 模板插入（App.tsx:1810-1852）。导出、批量导出、备份/恢复、置顶/收藏/归档、标签重命名、回收站操作均不在面板内。
- 建议：① 拼音全拼/首字母匹配（中文笔记用户高频诉求）+ 最近使用权重；② 用 `>` 前缀分流「命令」与「笔记」（类 VSCode）；③ 把上述高频操作纳入面板，让 Ctrl+K 成为"能到达一切"的入口。

### A3. 保存失败的反馈与兜底
- 现状：保存失败仅顶栏静态"保存失败"文字（App.tsx:1100-1105），无 Toast、无重试按钮；自动保存为 650ms 防抖（App.tsx:1118-1124），无 blur/beforeunload 兜底 flush。
- 建议：失败时 Toast + 「重试」按钮（Toast 组件已带 action 能力，App.tsx:2907-2912，改动极小）；窗口 blur 时触发一次 saveActive 兜底。

### A4. 弹窗焦点管理与组合键冲突
- 现状：所有模态无焦点陷阱、关闭不还焦（Modals.tsx:89-94、CommandPalette.tsx:24-26），Tab 可穿透到遮罩后方；盘点发现 App.tsx:962-965 附近存在 Tab 系组合键拦截，若确为 `Alt+Tab` 会与系统窗口切换冲突（README 声明的是 `Ctrl+Tab`，建议复核）。
- 建议：统一 focus-trap 工具（keydown 拦截 Tab 循环 + 关闭还焦触发元素）；复核并固定为 `Ctrl+Tab` / `Ctrl+PgUp·PgDn`。

### A5. 列表右键菜单与多选批量操作
- 现状：卡片仅 hover 操作按钮组（置顶/收藏/归档/删除，DocumentListPage.tsx:293-368），无右键菜单、无多选。
- 建议：① 卡片右键菜单（打开 / 新标签打开 / 置顶 / 收藏 / 归档 / 导出 / 删除），与编辑器块右键菜单体验对齐；② `Ctrl/Shift+点击` 多选 + 底部批量操作条（移入文件夹 / 加标签 / 归档 / 删除）——这是管理大量记录时的核心效率功能。

### A6. 窗口位置与尺寸记忆（快赢）
- 现状：每次启动固定 1080×720（main.ts:2178-2201），无 bounds 持久化。
- 建议：关闭时保存 bounds 到设置文件，启动恢复（主进程十几行代码）。

### A7. 快速捕捉工作流打磨
- 现状：`Ctrl+Alt+B` / 托盘「快速新建」每次必建新空白记录（main.ts:2331-2334 → handleCreate），且该热键写死不可配置（main.ts:2329）。
- 建议：① 呼出时若当前活动笔记是"空占位记录"（0.9.101 的 isBlankNote 已有此判定）则直接聚焦输入，不再重复新建——与刚上线的空记录清理天然协同；② `Ctrl+Alt+B` 移入设置可自定义；③ 可选：为「保存剪贴板为记录」也配全局热键（现在仅托盘入口）。

### A8. 搜索结果深度
- 现状：FTS 命中仅返回 ID 集合并入过滤（App.tsx:1168、1214），列表摘要仍是固定 excerpt，无命中上下文片段；标签过滤仅单选；无手动排序。
- 建议：① 用 SQLite FTS5 `snippet()` 返回命中句片段，搜索时替换摘要位置显示（改动集中在主进程 searchNotes + 列表摘要字段）；② 标签多选（AND/OR 切换）；③ 排序加「手动」档（配合 B5 拖拽排序）。

## B. 布局微调（骨架与位置不动）

### B1. 面板宽度可拖拽调节
- 现状：侧栏固定 260px（layout.css:5-19，折叠 80px）、InfoPanel 固定 300px（info-panel.css:9）、FormatPanel 固定宽浮层（format-panel.css:15），均不可调；长文件夹名/标签只能截断。
- 建议：加 resize 手柄（侧栏 180-400px、InfoPanel 240-420px 区间），宽度存 localStorage。**位置、层级、折叠逻辑全部不变。**

### B2. TabBar 显式网格定位
- 现状：TabBar 无任何 grid 定位规则（仅 topbar.css:105-114 外观），作为 app-shell 网格自动放置项，且仅 >1 标签时渲染（TabBar.tsx:15），标签数 1→2 时顶栏下方会突跳。
- 建议：给 app-shell 显式声明 tab 行的 grid-row，或让 TabBar 常驻占位（单标签时也保留行高），消除突跳。视觉位置不变。

### B3. 列表规模化（虚拟滚动/渐进渲染）
- 现状：DocumentListPage 全量 map 渲染所有卡片（DocumentListPage.tsx:262），无虚拟滚动/分页；笔记上千后首屏与滚动会劣化。
- 建议：先做零依赖渐进渲染（首屏 N=60 + IntersectionObserver 滚动加载），必要时再上虚拟列表。布局形态（卡片网格）不变。

### B4. 加载态
- 现状：除版本历史外无任何 loading/skeleton（WorkspaceHome、DocumentListPage 均直接渲染）。
- 建议：首屏与切库/恢复备份等重操作加轻量骨架占位，避免闪空。属补充，不挪任何现有元素。

### B5. 拖拽排序补全
- 现状：笔记卡片可拖入侧栏文件夹/标签归类（DocumentListPage.tsx:113-116、Sidebar.tsx:222-237），但文件夹/标签列表不可拖拽排序、列表卡片不可拖拽排序（仅 4 档下拉排序）；侧栏分区默认收起，拖拽悬停无自动展开反馈。
- 建议：① 侧栏文件夹/标签拖拽排序（顺序存 note_meta 之外的小 JSON）；② 列表「手动排序」档 + 卡片拖拽换序；③ 拖卡片悬停侧栏分区 400ms 自动展开。

### B6. 窄屏专项验证（design-qa 遗留）
- design-qa.md 遗留：FormatPanel 在 980px 以下的展开/收起未验证。按约束只验证与修补，不改面板位置。

## C. 功能深化

| 项 | 现状 | 建议 |
|---|---|---|
| C1. 设置导入导出 | 无 | 导出/导入设置 JSON（换机、重装场景） |
| C2. 模板系统显式化 | 靠「文件夹名为『模板』」的隐式约定 | 模板管理入口 + 「从模板新建」；模板变量扩展 `{{folder}}` `{{tags}}` |
| C3. 回收站与存储管理 | 仅按天数自动清理 | 回收站数量/占用统计 + 一键清空；整库存储统计（笔记/附件分别统计） |
| C4. 提醒时间自定义 | 仅 20min/1h/3h/明早9点 四档 | 自定义日期时间选择 |
| C5. 批量导出 PDF | 批量仅 HTML/MD/TXT/JSON，PDF 仅单篇 | 批量 PDF（走打印管线逐篇导出） |
| C6. 附件清理入口 | 主进程已有 cleanupUnreferencedAssets（main.ts:1940）但仅在删笔记时被动触发 | 设置里加「清理未引用附件」手动操作 + 预览将删除的文件 |
| C7. 剪贴板捕获热键 | 仅托盘菜单入口 | 可选全局热键，随手存剪贴板 |

不建议近期做（与定位/约束冲突）：多窗口分屏（布局大改）、云同步（偏离本地优先定位，若要做需产品层单独论证）。

## 事实底稿（代理盘点原文摘录）

- 布局：CSS Grid `260px / 1fr` 两列 + `44px / 1fr` 两行（layout.css:5-19）；断点 1279（InfoPanel 变浮层）/ 980（单列+侧栏浮层）/ 760（侧栏近全宽）；专注模式直接隐藏侧栏与面板（layout.css:87-91）。

- 搜索：侧栏检索框，120ms 防抖（App.tsx:1045-1049）→ FTS5 bm25 排序 limit 1000（main.ts:1373-1398）；语法 tag:/folder:/fav/archive/trash。
- 自动保存：idle/dirty/saving/saved/error 五态（App.tsx:146），顶栏展示（TopBar.tsx:22-28、70-72）。

- 安全：PIN 加密 db/备份；闲置锁+隐藏锁+挂起锁（main.ts:2251-2272、2646-2649）。
